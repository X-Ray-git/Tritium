# 存储与缓存

## Hive Box

- `settings`：主题模式、默认首页、回答/评论排序、刷新率和触觉反馈偏好。
- `user`：登录标记、Cookie 和当前用户信息。
- `cache`：可丢弃的运行时缓存，以及仅保存在本机的阅读历史和正文进度。

存储路径位于系统应用支持目录下的 `hive` 子目录。测试可通过 `pathOverride` 使用
临时路径，不依赖真实设备目录。

## 迁移约定

删除偏好或改变含义时必须提供一次性清理或兼容读取。旧版动态取色和自定义颜色键已
在初始化时删除，品牌色始终由主题代码显式定义。

## 预加载

推荐流预加载必须同时保存条目、`nextUrl` 和 `isEnd`，消费后才能继续正确分页。
详情预加载复用对应 HTTP 模块的在途 Future，避免列表预加载与详情页重复请求。

预加载只用于性能优化，不是持久业务状态；失败不能阻止页面正常发起请求。

## 阅读历史

`ReadingHistoryService` 在 `cache` box 的 `reading_history` 键下保存最多 200 条本地
记录，覆盖问题、回答、文章、想法和用户。记录包含类型、内容 ID、标题、摘要、标准
URL、最近访问时间和正文进度；重复打开同一内容时置顶并合并已有摘要与进度。

历史写入通过单一 Future 队列串行执行，避免快速横滑回答时并发读改写互相覆盖。
`ReadingSession` 只给文章、回答和想法保存正文进度，终点是评论区前的正文锚点；
具体完成条件是该锚点到达视口下边缘。评论懒加载不得进入分母；正文初始已完整位于
视口内时保存 100%。阅读历史不上传知乎服务器，清空历史同时删除对应进度。
