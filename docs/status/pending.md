# 待办与真机边界

## 当前无桌面侧阻塞项

静态分析、自动测试、Android Debug/Release 构建和发布脚本均可在真机验收前完成。
后续代码问题应在发现时直接加入本页，不要只留在聊天记录中。

## 必须真机或外部配置

- 按[真机验收清单](device-acceptance.md)验证登录、真实接口、刷新率、布局和系统联动。
- 在不同 Android 版本和启动器遮罩下验收新版应用图标。
- 新包名与旧包名无法覆盖安装，发布前确定旧版数据和升级说明。
- 真机验收评论自动加载的触发时机：在不同屏幕高度、长短正文和连续多页评论中确认
  固定预加载距离不会过早连拉多页，也不会滑到底后出现明显停顿。该值保持内部实现
  细节，不增加用户设置。
- 真机验收顶部正文进度拖动与纵向滚动、回答横滑之间的手势竞争，并确认 24dp 隐形
  触摸区域不会遮挡正文首行操作。
- 使用真实知乎账户观察推荐反馈和会话去重：确认停滚可见与点击上报未触发风控，
  全重复刷新保留原列表。知乎服务端跨进程重复属于已知上游边界，不承诺彻底消除。
