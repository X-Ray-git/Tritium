# 待办与真机边界

## 当前无桌面侧阻塞项

静态分析、自动测试、Android Debug/Release 构建和发布脚本均可在真机验收前完成。
后续代码问题应在发现时直接加入本页，不要只留在聊天记录中。

## 非阻塞构建链升级

- Flutter 3.47 已提示 Gradle 8.14 即将停止支持，后续应升级至至少 9.1。
- Android Gradle Plugin 8.11.1 后续应升级至至少 9.0.1。
- Kotlin 2.2.20 后续应升级至至少 2.3.20。

三项应作为同一个 Android 构建链任务评估插件兼容性、签名构建和 Release CI；当前
Flutter 3.47 下 Debug/Release 均能成功，不作为本轮发布阻塞项，也不使用
`--android-skip-build-dependency-validation` 隐藏预警。

## 本轮新增的待真机项目

- 首页三页 PageView 的横滑手感、与设置页 Switch 的手势共存、离屏页面保活
  （不重新请求、不丢滚动位置）。
- 回答连续多页预取时机与加载占位页手感；滑入占位页不振动、失败重试可达。
- 正文链接矩阵（含 `link.zhihu.com`、`zhihu://`、相对路径）在真实浏览器的兜底
  行为与统一无效反馈。
- 正文文本选择与链接点击、图片手势、纵向滚动、回答横滑在同一页面共存。
- 代码块复制成功动画与深色模式对比度。
- 统计值 “—” 语义在真实接口缺失字段时的表现。

## 必须真机或外部配置

- 按[真机验收清单](device-acceptance.md)验证登录、真实接口、刷新率、布局和系统联动。
- 在不同 Android 版本和启动器遮罩下验收新版应用图标。
- 新包名与旧包名无法覆盖安装，发布前确定旧版数据和升级说明。
- 真机验收评论自动加载的触发时机：在不同屏幕高度、长短正文和连续多页评论中确认
  固定预加载距离不会过早连拉多页，也不会滑到底后出现明显停顿。该值保持内部实现
  细节，不增加用户设置。
- 真机验收顶部正文进度拖动与纵向滚动、回答横滑之间的手势竞争，并确认 24dp 隐形
  触摸区域不会遮挡正文首行操作。
- 使用真实知乎账户观察推荐反馈和会话去重：确认停滚可见与点击上报未触发风控，
  全重复刷新保留原列表。知乎服务端跨进程重复属于已知上游边界，不承诺彻底消除。
