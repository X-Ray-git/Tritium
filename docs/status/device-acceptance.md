# 真机验收清单

以下项目依赖 Android 系统、真实显示屏、WebView 或真实知乎账户，无法由桌面
构建和 Widget 测试完整替代。

## 已完成

- 2026-07-22：下拉刷新反悔回收路径与 AppBar 边界已在真机确认。
- 2026-07-22：回答页反向滚动标题时机、固定 AppBar 稳定性与设置页顶部安全距离已
  在真机确认。
- 2026-07-29：多图文章改为一次布局全部正文块后，阅读进度条不再随滚动逐块跳动，
  已在真机确认。

## 必须真机

- 完成 WebView 登录，验证 `z_c0/d_c0` Cookie 保存、过期与退出。
- 在已登录和未登录状态下分别浏览推荐、热榜、问题、回答、文章、想法与评论。
- 验证知乎实际分页字段、风控响应和签名算法是否仍与上游匹配。
- 验证 60/90/120Hz 设置、回答横滑手感、振动反馈和长列表掉帧情况。
- 检查小屏、异形屏、深色模式和系统字体放大后的导航、弹层与长文排版。
- 从浏览器分别点击问题、回答、文章、想法、用户、话题和 `zhihu://` 链接，确认
  Tritium 的冷启动、运行中复用和浏览器兜底行为。
- 在长文章、横滑回答和想法中验证进度条；退出重进后确认正文位置恢复，评论加载时
  进度不得后退。
- 检查新版主导航在手势导航、三键导航、深浅色和不同底部安全区下的位置与阴影。
- 在浅色纯色、深色和复杂列表背景上确认主导航连续圆角边缘清晰，没有白雾状断边。
- 验证详情页分享、复制链接和浏览器打开，以及阅读历史的打开、删除和清空。
- 验证根评论内缩略跟评的方括号表情和 HTML 表情无需打开楼中楼即可显示；普通图片
  附件仍只在完整评论视图展示。
- 保存图片到相册，验证 Android 7–16 对应的媒体权限和 Gal 插件行为。

## 发布前另行确认

- 使用正式 keystore 构建，并核对证书 SHA-256；当前本地 Release APK 是 debug 签名回退。
- 确认新包名 `io.github.xraygit.tritium` 的安装、覆盖安装策略与旧版数据取舍。
- 验收新版图标在不同 Android 版本、启动器和圆形/圆角矩形遮罩下的裁切效果。
  特别确认显示完整源图构图、只保留预制圆角，没有 Adaptive Icon 二次裁切；
  覆盖安装仍显示旧图时，先卸载应用以排除启动器图标缓存。
